## Evidence Discipline
Use these labels throughout this repository:
- **DOCUMENTED** — supported by an identified primary document.
- **CORROBORATED** — supported by multiple independent reliable sources.
- **REPORTED** — supplied by a witness/family member but not yet independently proven.
- **LEAD** — fact or source requiring verification.
- **DISPUTED** — conflicting evidence exists.
- **INFERENCE** — reasonable interpretation, not itself a fact.
- **NOT ESTABLISHED** — evidence currently insufficient.

Never convert a suspicion into a factual assertion merely because several unusual facts appear together.
